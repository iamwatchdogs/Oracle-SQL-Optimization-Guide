Picture a shelf with 19 research papers that all promise faster SQL.

Only 3 of those papers were written by Oracle engineers about Oracle itself, so start there and treat the rest as ideas to test.

A paper stack is like a parts shelf, except half the parts were built for a different engine.

<details><summary>In case you don't know about peer review, it's independent checks by other researchers before a paper is published.</summary>Venue names such as PVLDB, SIGMOD, and OOPSLA tell you that check happened. Dates and test systems tell you the rest.</details>

This chapter has 3 topics. First you learn a 4-step read method. Then you meet the 3 Oracle papers from 2023 to 2026. Then you learn what does not move to Oracle without extra proof.

All sources were checked on 2026-09-22. Full reads are marked. Snippet-only reads are marked.
